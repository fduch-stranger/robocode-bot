# Tank Royale Turn Timing

The repo targets upstream Tank Royale 1.3.1 (runner in `tools/battle-runner/pom.xml`, Python Bot API in `requirements.txt`). Every game-type preset (1v1, melee, classic, twinduel, custom) in `lib/common/.../rules/GameTypePreset.kt` sets `turnTimeoutMicros = 30_000`; `DEFAULT_TURN_TIMEOUT_MICROS = 5_000` in `RuleDefaults.kt` is only a low-level server fallback. Local `tools/battle-runner` uses `BattleSetup.oneVsOne`/`melee` presets, so local battles run at 30 ms. Treat the runtime `Bot.turn_timeout` property as source of truth for warning thresholds. Default TPS is 30, but TPS is not the bot compute budget.

Python Bot API flow: server sends `TickEventForBot`; the bot thread runs event handlers and local decision code; `go()` dispatches queued events, sends `BotIntent`, then waits for the next tick. The analysis budget is everything between tick receipt and sending intent inside `go()`. If the bot misses the deadline, `SkippedTurnEvent` is sent for the previous turn. Server-side `ModelUpdater` keeps a persistent `botIntentsMap` and merges only newly received fields, so a skipped turn effectively repeats the last stored commands rather than creating a fresh zero intent.

Engine order facts verified with telemetry: a bullet leaves along the gun heading from before that turn's gun rotation (bullet direction = gun direction when `set_fire` was called), from the pre-move position; scanned enemy energy is recorded before bullet hits resolve, so a hit on turn T shows in scans from T+1.

Current project instrumentation: shared `TurnTimingTelemetry` emits sampled `bot.turn_timing` and immediate `bot.skipped_turn` records. Severity scales to the runtime `turn_timeout` (`warn` at 50%, `danger` at 80%, `critical` at 10% remaining). Adaptive Prime decision time is ~5 ms median / ~10 ms p90 with rare 100+ ms spikes; the BasicGFSurfer port is microseconds. CPU contention (parallel agents, tests) skews Adaptive results, so benchmark on a quiet machine. `tools/intent_gap_summary.py` summarizes missing/duplicate intent turns from `--intent-diagnostics`.
